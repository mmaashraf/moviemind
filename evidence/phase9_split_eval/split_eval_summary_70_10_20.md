## How `val_features.csv` is used now

- `src/tune_dl.py`: Optuna objective evaluates each trial on `val_features.csv` (not test).
- `src/dl_model.py`: epoch-wise validation reports now use `val_features.csv` (with fallback to test only if val file is absent for backward compatibility).
- `src/tune_ml.py`: RF/GB hyperparameter search scores each trial on validation split before final test comparison.
- `src/ml_models.py`: still train/test only by default (no dedicated val loop yet).
- `test_features.csv` remains reserved for final unbiased evaluation/reporting for tuned flows.
