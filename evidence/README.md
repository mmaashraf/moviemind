# Evidence and Observations Folder

This folder stores run outputs, observations, and proof artifacts for each phase.

## Structure
- `demo/`: Playwright demo videos (`video/moviemind_demo.webm`, `video/moviemind_capstone_notebook.webm`) — see [`demo/README.md`](demo/README.md).
- `phase5b/`: Optuna tuning logs, observations, and result snapshots.
- `phase6/`: Post-analysis outputs (embeddings, PCA/t-SNE plots, feature importance, summary).
- `code_reviews/`: Periodic code-review notes with findings and fixes.

## Rule
Every major run should leave evidence here so progress is reproducible and auditable.
